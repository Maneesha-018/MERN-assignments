# To-Do App – Release Candidate

## Project Description
A To-Do List application that helps users manage daily tasks.

## Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Filter all, pending and completed tasks
- Save tasks using LocalStorage
- Maintain tasks after page refresh

## Technologies
- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` using Live Server.
3. Add and manage your tasks.

## Release Status
Feature-complete release candidate submitted for testing.
