
# Arrays and Strings Problem Set

## Objective
To practice JavaScript arrays and string operations.

## Problems Covered
1. Find the largest number in an array.
2. Reverse an array.
3. Reverse a string.
4. Check whether a string is a palindrome.

## Technologies Used
- HTML
- CSS
- JavaScript

## Sample Output
- Largest Number: 40
- Reversed Array: 30, 20, 10
- Reversed String: olleH
- Palindrome: It is a Palindrome.

## Conclusion
This assignment helped me understand JavaScript arrays,
strings and their built-in methods.
