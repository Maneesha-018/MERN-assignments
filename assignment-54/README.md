# To-Do App

## Project Description
This is a simple To-Do List application developed using HTML, CSS and JavaScript.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Prevent empty task submission.

## Technologies Used
- HTML
- CSS
- JavaScript
