
# Interactive Profile Page

## Objective
To create an interactive profile page using HTML, CSS and JavaScript.

## Features
1. Activate and deactivate profile.
2. Highlight and remove highlight from profile.
3. Display profile status messages.
4. Update button states using JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## JavaScript Concepts
- addEventListener()
- classList.toggle()
- setAttribute()
- DOM Manipulation
- Accessibility attributes

## Conclusion
This project helped me understand JavaScript events,
CSS classes and accessible interactive elements.
