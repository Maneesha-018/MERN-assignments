
# Product Catalogue

## Objective
To create and validate a product catalogue using JSON.

## Project Files
- catalogue.json: Stores product information.
- script.js: Validates JSON data using JavaScript.

## Catalogue Details
The catalogue contains the following products:
1. Laptop
2. Mobile
3. Shoes
4. Watch

## Technologies Used
- JSON
- JavaScript

## Validation
JSON.parse() is used to convert JSON data into a JavaScript object.
Try-catch is used to handle JSON errors.

## Conclusion
This assignment helped me understand JSON structure,
data storage and JSON validation.
